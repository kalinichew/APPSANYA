# 🏃 Поймай Саню!

Небольшая браузерная игра на реакцию: Саня бегает по игровому полю, а задача игрока — поймать его, пока он не убежал.

## ✨ Что умеет игра

- **Три уровня:** поймай Саню 10, затем 20 и наконец 150 раз.
- **Прогресс каждого уровня:** шкала показывает, сколько захватов осталось до следующей цели.
- **Поддержка телефона и компьютера:** можно нажимать мышью или касаться картинки; поле подстраивается под размер экрана.
- **Движение в пределах поля:** Саня не выходит за границы игровой области, а с каждым уровнем ускоряется.
- **Обратная связь:** короткая анимация подтверждает захват, а сообщения подбадривают по мере приближения к цели.
- **Финал и повтор:** после третьего уровня появляется экран завершения с возможностью сыграть ещё раз.

## 🎮 Как играть

1. Нажми **«Начать игру»**.
2. Лови Саню нажатием мыши или касанием на телефоне.
3. Следи за текущей целью и шкалой прогресса.
4. Пройди уровни по порядку: **10 → 20 → 150 захватов**.

Счётчик в верхней части экрана показывает общее число захватов за игру. На новом уровне его цель сбрасывается, а общий счёт продолжает увеличиваться. Всего для прохождения нужно **180 захватов**.

## 🚀 Запуск

Игра не требует сборки, backend или установки npm-пакетов. Можно открыть `index.html` в браузере. Для локального HTTP-сервера из папки проекта выполни:

```bash
python3 -m http.server 8000
```

Затем открой [http://localhost:8000](http://localhost:8000).

> Изображения игрового поля и Сани загружаются с внешнего хостинга, поэтому для их отображения нужно подключение к интернету.

## 🛠 Настройка

Цели уровней задаются массивом `levels` в `javascript.js`:

```js
const levels = [10, 20, 150];
const levelSpeedMultipliers = [1, 1.4, 1.8];
```

Массив `levels` задаёт число захватов на каждом этапе, а `levelSpeedMultipliers` — множитель скорости для соответствующего этапа. Чтобы изменить сложность, отредактируй значения по порядку в обоих массивах. Счётчик, шкала прогресса и номер уровня обновляются на основе `levels`.
